Claude Fable 5.2 is out, 20% cheaper, and on Bedrock from day one

Anthropic shipped its new flagship on Sunday and the whole stack moved with it: Claude Code 2.1.321 made it the default Fable, both Agent SDKs got matching releases, and Bedrock lists it as a covered model with new retention rules. Underneath the headline there is a lot that touches an Agent SDK framework on AWS: a breaking thinking-block check, a fail-closed hook option in the Python SDK, AgentCore Runtime V2 in ten Regions, and the document skills going Apache 2.0.

Top of the day

  1. Claude Fable 5.2 and Mythos 5.2 launched Nov 9: 1M context, 128k output, $8/$40 per MTok (down from $10/$50), on Bedrock as anthropic.claude-fable-5-2.
  2. Before switching an Agent SDK framework to 5.2, read the breaking changes: thinking-block prefix binding is enforced for everyone, the old computer-use tool only works on Bedrock, forced tool_choice returns 400.
  3. Claude Code 2.1.319 to 2.1.322: MCP tool calls run as background tasks, permissions.denyInsteadOfPrompting for unattended runs, security fixes, fast mode on Vertex.
  4. Python Agent SDK 0.2.177 added HookMatcher(on_failure="block"), so a PreToolUse guardrail that crashes now blocks instead of allowing.
  5. AgentCore Runtime V2 is now in 10 Regions with ~2 s cold starts; AgentCore Gateway got a built-in Web Answer connector.
  6. The docx, pdf, pptx and xlsx skills were relicensed to Apache 2.0 on Nov 6, so you can vendor them into an internal framework.
  7. Side-business signal of the week: one MCP server per vertical, agent billing layers, and agent-session secret scanning all hit Product Hunt or Hacker News front pages.

Claude Platform docs2026-11-09

What's new in Fable 5.2: the breaking changes you must handle before switching

The preserved-thinking prefix check is now enforced for every account: editing system prompt, tools or earlier messages and then replaying a 5.2 thinking block returns a 400. Only Fable/Mythos 5.2 can read 5.2 thinking blocks; falling back to Opus 5.5 silently drops them. The computer_20251124 tool returns 400 everywhere except Bedrock. Forced tool_choice (any / specific tool) returns 400, thinking cannot be disabled, default effort is high. 30-day retention is required.

Why it matters: If any part of your framework builds raw Messages requests (routers, compaction, retries, model fallback), make conversation history append-only first. The docs say nothing changes if the Agent SDK builds the requests for you.

Anthropic research2026-11-06

Engineering: The components of agent memory

Lance Martin lays out a memory hierarchy: searchable transcripts, memory notes, wiki-style memory representations, and a small injected context layer, plus offline "dreaming" passes where Claude reviews logs and fixes its notes. Reported results: CL-Bench reward from 0.564 to 0.828 with memory; wiki accuracy from 13% to 48% over 128 dreaming sessions. Why it matters: A concrete blueprint for a memory layer in your harness: an S3 or EFS-backed memory directory plus a scheduled dreaming job. It needs no Anthropic-side memory store, so it works on Bedrock.
